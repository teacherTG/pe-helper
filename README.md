# 체육 업무 도우미

중학교 체육 교사용 웹 앱입니다. 휴대폰이나 패드로 수업 중에 바로 씁니다.

- **업무관리**: 업무일자, 마감기한, 업무내용을 적고 진행중과 완료를 나눠 봅니다. 마감이 가까우면 D-day로 표시합니다.
- **수행평가**: 명렬표를 붙여넣으면 학생별 평가 항목이 나타납니다. 기록(초, 개수, 점수)을 넣거나 시기별로 ○/×를 누르면 평가계획의 배점으로 자동 환산됩니다.
  - 1학년: 체력운동과 레이저 사격(50), 플라잉디스크(50)
  - 2학년: 플레이트야구(60), 탁구(40)
- **교과세특**: 점수 수준과 관찰 메모를 바탕으로 세부능력 및 특기사항 문장을 만듭니다. 기재요령에 따라 명사형 어미로 끝내고 1,000Byte 안으로 맞춥니다. 같은 반 학생끼리 문장이 겹치지 않게 고릅니다.

## 구조

```
index.html        프론트엔드 (GitHub Pages로 배포)
backend/Code.gs   백엔드 (Google Apps Script 웹 앱, 구글 시트에 저장)
```

프론트엔드는 `fetch`로 Apps Script 웹 앱 주소에 `POST {key, action, ...}` 요청을 보냅니다. 백엔드는 비밀 키가 맞을 때만 읽고 씁니다.

| action | 하는 일 |
|---|---|
| `ping` | 연결 확인 |
| `loadAll` | 저장된 반과 업무 데이터를 모두 읽음 |
| `saveDoc` | 반 하나 또는 업무 목록을 저장하고, 보기용 시트(예: `1학년 3반`, `업무관리`)를 새로 씀 |
| `deleteDoc` | 반 삭제 |

## 설치

### 1. 백엔드 (구글 시트 + Apps Script)

1. 구글 시트를 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. `backend/Code.gs` 내용을 붙여넣고, `API_KEY`를 나만 아는 긴 문자열로 바꿉니다. **진짜 키는 이 저장소에 올리지 마세요.**
3. **배포 → 새 배포 → 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** (GitHub 페이지에서 호출하려면 필요합니다. 키가 없으면 아무것도 읽거나 쓸 수 없습니다.)
4. 나온 웹 앱 주소(`https://script.google.com/macros/s/…/exec`)를 복사합니다.

코드를 고친 뒤에는 **배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다.

### 2. 프론트엔드 (GitHub Pages)

저장소 **Settings → Pages → Source: Deploy from a branch → main / (root)** 를 고르면 `https://<아이디>.github.io/<저장소>/`에 올라갑니다.

### 3. 연결

앱 오른쪽 위 저장 상태 표시(`이 기기에만 저장 · 시트 연결`)를 누르고 웹 앱 주소와 비밀 키를 넣습니다. 기기마다 한 번씩 넣으면 됩니다. 키는 그 기기의 브라우저에만 저장됩니다.

### 4. 관찰 메모 → AI 세특 문장 (선택)

교과세특의 관찰 메모를 기재요령에 맞는 문장으로 바꾸는 기능입니다. Apps Script 백엔드가 Claude API를 대신 호출하므로 API 키는 GitHub에도, 브라우저에도 남지 않습니다.

1. [Claude Console](https://console.anthropic.com)에서 API 키를 만들고 결제 수단(크레딧)을 등록합니다. Claude 구독과는 별도로 사용량만큼 청구됩니다.
2. Apps Script **프로젝트 설정(톱니바퀴) → 스크립트 속성 → 속성 추가**
   - 속성: `ANTHROPIC_API_KEY`, 값: 발급한 키
   - (선택) `ANTHROPIC_MODEL`: 기본은 `claude-opus-5-5`. 비용을 줄이려면 `claude-haiku-5-5`
3. 키를 넣은 뒤 처음 한 번은 **배포 관리 → 새 버전으로 배포**하고, 외부 요청 권한(UrlFetchApp) 승인 창이 뜨면 허용합니다.

AI에는 학년, 항목별 수준(상·중·하), 메모, 이미 쓴 다른 문장만 보내고 학생 이름은 보내지 않습니다.

## 개인정보

- 학생 이름과 점수는 **구글 시트에만** 저장되고 이 저장소에는 들어가지 않습니다.
- 연결하지 않은 상태에서는 그 기기의 브라우저(localStorage)에만 저장됩니다.
- 세특 문장은 NEIS에 입력하기 전에 학생의 실제 모습과 맞는지 꼭 확인하세요.
